# 承認済みの作風

ユーザーが「意図通りの音楽」と確認した2つの作風（2026-11-01）と、どのゲームにも共通する作曲の決まりです。次の曲を作るときは、まずここに合わせます。変えるときは、ユーザーの指示を優先します。

## 共通の決まり

- **旋律はすべてオリジナル**。既存のゲーム曲・映画音楽の旋律を使わない。「〇〇風」と頼まれても取り入れるのは作風の特徴だけ。AIへのプロンプトにも作品名を書かない。
- **動機で束ねる**。ゲームごとに2〜3個の短い動機（4音前後）を決め、曲ごとに長調・短調・拡大・刻み・ファンファーレなどに姿を変えて織り込む。
- **区間で色を替える**。A→B→A2→C のように区間ごとに主旋律の楽器を替える。同じ旋律が戻ってくるときは、オクターブや重ねる楽器を変える。
- **主旋律を埋もれさせない**。各区間で主旋律が最大のパートから3dB以内。ホルンのオクターブ下の重ねや低音の刻みは強く出やすいので、ベロシティを下げて調整する。
- **楽器の都合を守る**。音域外は書かない。管楽器の長音は約4秒、弦は約6〜8秒まで（`INSTR` の最長秒数）。長い和音は小節ごとに弾き直す。
- **ループ**。最後の小節は頭へ戻る和音（多くはV、またはV7）で終える。テンポは 60・64・75・80・96・100・120・125・150・160 BPM など「1拍が整数マイクロ秒」になるものを使い、ループ長を64サンプルの倍数にする（`validate` が確認する）。
- **試聴を前提にする**。自動検査は最低限の確認にすぎない。仕上がりは人の耳で決める。

## 作風A：モンクエ（クロノ・トリガー風のオーケストラ）

ねらい：90年代の日本のRPGの作曲の魅力を、本物のオーケストラの響きで鳴らす。歌える旋律と、場面ごとにはっきり違う色。

- **和声**：旋法の響き（ドリアン、♭VIIを使うミクソリディアン）、7th・9th、IV–V–iii–vi、借用和音（ii–iv、♭VI、♭II）、区間の途中での全音上への転調。
- **リズム**：シンコペーションするベース（`synco`）、行進の小太鼓（`march`）、戦闘は8分で刻む低音（`drive8`）と金管の打ち込み。
- **動機**：主人公の主題「5-1-2-3」、焚き火の動機「3-2-1-5̣ / 6̣-1-2」、世界の異常の動機「1-♭2-1-♯4」。
- **長さ**：1ループ46〜77秒、A→B→A2（→C）。ジングルはループなしで約14秒。
- **場面ごとの型**

| 場面 | テンポ・拍子 | 主な色 |
|---|---|---|
| タイトル | 96〜125 BPM | ホルン＋チェロの主題 → 総奏（トランペット・ティンパニ・シンバル） |
| 町・村 | 100〜125 BPM、3拍子も | フルート・クラリネット・オーボエ、ハープ、ピチカートの裏拍、タンバリン |
| フィールド | 120 BPM | バイオリン＋フルート、スピッカートの刻み、行進の小太鼓、♭VII |
| ダンジョン | 80 BPM | オーボエ、ハープの反復、弦トレモロ、ドラ、持続低音 |
| 戦闘・ボス | 150〜160 BPM | トランペット＋バイオリン、金管の打ち込み、`drive8`/`synco`、打楽器を強めに |
| 物語の場面 | 64〜80 BPM | 独奏（ホルン・チェロ・独奏バイオリン・オーボエ）とハープ |

見本：`projects/monque/`（`score.py` が最初の5曲、`pieces_*.py` が残り）。

## 作風B：甲殻類（深海・長時間でも飽きない）

ねらい：深度50,000mへ潜る冒険の、広大で静かな深海。ジブリ映画のような郷愁と、探索中に何十分流しても疲れない音。

- **長さとテンポ**：1ループ2〜3分。50〜80 BPM（タイトル・ワルツは96 BPMの3拍子も）。
- **和声の動き**：1〜2小節ごとにゆっくり変える。旋法はリディア（驚き・光）、ドリア（深さ・静けさ）、短調（未踏・暗さ）。強い終止で区切らず、ループの頭に戻っても気づきにくくする。
- **旋律**：長い音と休み（`r:4`）を多めに。2小節で呼びかけ、2小節休む。区間ごとにフルート→ホルン→静かな弦（`vln1_q`）のように受け渡す。
- **深海の色**：
  - 発光生物のきらめき：`shimmer()` で、ハープ・グロッケンの高音を小節ごとに違う位置・高さに鳴らす。乱数の種を固定するので、毎回同じ曲になる
  - 水：マリンバの8分の揺れ
  - 遠さ：チューブラーベル、弱音器付きホルン、弦トレモロ
  - 巨大生物：トロンボーン＋テューバ（オクターブ下）の長い呼び声
  - 深さ：持続低音（`pedal`）、ドラ、弓で擦るシンバル
- **打楽器は控えめ**。リズムの刻みより、持続と響きで空間を作る。総奏はタイトルのクライマックスだけにする。
- **音量**：静かな区間と総奏の差が大きいと、ピークに合わせて全体が小さくなる。−17.6 LUFS 程度までは許容し、SOUNDVAULTの `volume` で補う。ゲーム内では効果音や会話に合わせて0.5〜0.7に下げてもよい。
- **動機**：潜行の動機「5-3-1-5̣」と、リディアの♯4で上がる答え。鯨の呼び声。

見本：`projects/crustaceans/pieces_crust.py`。

## 作曲の進め方

1. ゲームの資料（世界観・場面・既存の音楽仕様）とキービジュアルを読み、作風と動機を決める。
2. 曲ごとに「調・テンポ・拍子・長さ・構成（区間ごとの楽器）」を1行で決めてから、旋律を書く。
3. `validate` で、小節の長さ・強拍の和音（85%以上が目安）・音域・ループ長を確かめる。
4. `render` のあと、`render.json` の `balance`（主旋律が埋もれていないか）と `part_peaks_db`（どのパートがピークを作っているか）を見て直す。
5. `qa` で、ラウドネス・ピーク・継ぎ目・類似度を確かめる。
6. 試聴ページを作って人が評価する → 直す → `export` で SOUNDVAULT に登録し、PRで公開する。
